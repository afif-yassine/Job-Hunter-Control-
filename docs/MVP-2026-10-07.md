# Livraison MVP du 7 octobre 2026

Le parcours standard compare le profil aux compétences déjà extraites, sans nouvelle analyse LLM par étudiant. Les CV numériques sont lus localement puis structurés avec Gateway. Les recherches nommées et filtres avancés complètent la recherche.

Les appels payants échouent sans démarrer si les compteurs sont indisponibles. Une réservation par compte sérialise les nouveaux kits ; les lectures du catalogue ont leurs propres réservations et contrôles de version. Le contrôle de disponibilité des offres est partagé et ne consomme aucun token.

## Ordre d’activation

1. Vérifier tests, build et CI de la branche `codex/mvp-completion`.
2. Appliquer `20261007111753_mvp_generation_and_reader_leases.sql` après vérification de l’absence de génération active. La migration révoque la réservation aux clients authentifiés : le serveur utilise désormais le client de service.
3. Conserver `AI_GENERATION_LEASES=1`, activer `AI_READER_LEASES=1`, sans changer le plafond Gateway existant de 2 USD.
4. Publier et contrôler les routes, permissions et progression du catalogue.

## Validation

181 tests réussis, un test LaTeX ignoré faute de compilateur ; 42 assertions PostgreSQL/pgvector ; TypeScript et lint sans erreur (trois avertissements préexistants). Test de mutation du quota détecté et code restauré. Filtres testés dans Chrome isolé à 390 et 1440 px sans débordement. Audit de dépendances de production : zéro vulnérabilité signalée.

## Limites à conserver visibles

- Les PDF scannés ne sont pas pris en charge par ce parcours ; aucune extraction partielle silencieuse.
- Le contrôle HTTP confirme l’accessibilité de la page ; une page HTTP 200 peut encore contenir une offre expirée. Une erreur ou redirection n’est pas une preuve de retrait.
- L’alerte sur 30 jours est un indicateur administrateur ; le budget de la clé Gateway demeure la limite effective. Certains anciens coûts sont estimés lorsque le fournisseur ne les a pas transmis.
- Les reformulations du CV et de la lettre restent à relire et approuver. Aucun envoi de candidature automatique.
- SMTP déclaré configuré ; expéditeur, réinitialisation complète et protection contre les mots de passe divulgués doivent être vérifiés avant ouverture publique.
- Avis de sécurité `braces` sans correctif publié dans la chaîne ESLint de développement : suivre le correctif, ne pas rétrograder le framework.
- Un retour à une ancienne version utilisant les réservations avec le client utilisateur échoue de façon fermée après la migration. Ne pas rétablir des permissions faibles pour contourner cette erreur ; conserver le correctif serveur de réservation lors d’un retour de version.
